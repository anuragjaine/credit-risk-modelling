# Data

## Source
LendingClub Loan Data from Kaggle
https://www.kaggle.com/datasets/wordsforthewise/lending-club

## Files
- raw/accepted_2007_to_2018Q4.csv : Original dataset (not tracked by git)
- processed/loans_cleaned.csv : Cleaned dataset after preprocessing (not tracked)

## Download Instructions
1. Create Kaggle account at kaggle.com
2. Go to the link above
3. Download accepted_2007_to_2018Q4.csv.gz
4. Place file in data/raw/ folder
5. Run notebook 01_data_understanding.ipynb
